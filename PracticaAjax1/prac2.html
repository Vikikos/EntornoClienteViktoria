Practica Ajax 2

Realiza una aplicación web que pida al usuario un número que represente el ID de un producto. Al pulsar un botón, deben realizarse las siguientes acciones:
1. GET:
Llamar a https://dummyjson.com/products/{id} sustituyendo {id} por el número introducido. o Si la petición es correcta, mostrar en pantalla:

  • el id
  • el título del producto
  • el precio
o Si el producto no existe (por ejemplo, letras o números fuera del rango), la API devolverá un error y debe mostrarse el status correspondiente (404).

2. POST:
Con los datos obtenidos en el GET, hacer una petición POST a https://httpbin.org/post enviando en el body un JSON con:
  • id
  • title
  • price
La respuesta de esta API devuelve dentro de la propiedad json el mismo objeto enviado. Debe mostrarse en la pantalla el title devuelto por el POST.

3. STATUS:
Si todo ha ido bien, mostrar 200. Si hubo error en el GET, mostrar el código de error recibido (404, etc.). El ejercicio puede resolverse con promesas o con async/await.
